# Nebula Mobile Android

Native Android Studio client for NebulaServer using Kotlin, Jetpack Compose, Retrofit, and Material 3.

Open this folder in Android Studio. The server URL must be reachable from the phone, for example `http://192.168.1.10:<Server:Port>`; allow the configured server port through Windows Firewall. Pair with the JSON payload shown by the NebulaServer dashboard QR. A debug APK is produced at `app/build/outputs/apk/debug/app-debug.apk`.
